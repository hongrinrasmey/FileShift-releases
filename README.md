# FileShift

A free, offline Android app that converts, compresses and organises files on your phone.

- No account, no ads, no uploads. The app has no internet permission.
- It always saves a new copy and never changes your original files.
- Android 9 or newer. English and Khmer.

This repository only holds the app downloads. The source code is private.

## Download

**[Get the latest version](https://github.com/hongrinrasmey/FileShift-releases/releases/latest)**: download the `.apk` file under **Assets**.

## Install

1. Open the downloaded `.apk` file on your phone.
2. If Android asks, allow your browser or file manager to install unknown apps.
3. Tap **Install**.

## Update

Download the newer `.apk` and install it over the old one. Your settings and History stay.

## Check that the file is genuine

Every FileShift release is signed with the same key. Its certificate SHA-256 fingerprint is:

```
3fb989dddedbd5b4ef2345b463d2ed58a9070d2cd6b62dc49f0872bdaf1e4c26
```

Android refuses to install an update signed with a different key, so a fake update can't replace the real app.
Each release also lists the SHA-256 of its `.apk` file.
